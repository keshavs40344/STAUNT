# STAUNT — Production Deployment Guide

This guide covers deploying the STAUNT Search Engine and building the desktop/mobile browser clients.

---

## 1. Deploying the Search Engine

### Option A: Render.com (Recommended)
The repository includes a root `render.yaml` configuration:
1. Connect your GitHub account to Render.com.
2. Select **Blueprints** -> New Blueprint Instance.
3. Link the repository: `https://github.com/keshavs40344/STAUNT.git`.
4. Render will automatically detect `render.yaml` and configure:
   - Root directory: `search-engine`
   - Build command: `pip install -r requirements.txt`
   - Start command: `gunicorn wsgi:app --bind 0.0.0.0:$PORT --workers 2 --threads 4 --timeout 120`
   - Health check: `/health`
5. Under Environment Variables, set:
   - `GROQ_API_KEY`: (Your Groq API Key)
   - `TAVILY_API_KEY`: (Your Tavily API Key)
   - `SECRET_KEY`: (Auto-generated by Render)

### Option B: Local / Self-Hosted Server (Waitress / Gunicorn)
```bash
cd search-engine

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Run with WSGI runner
python wsgi.py
```

### Option C: Cloudflare Tunnel (Development / Remote Testing)
```bash
# Run local search server
python search-engine/wsgi.py

# In another terminal, run cloudflared tunnel
cloudflared tunnel --url http://127.0.0.1:5000
```

## 2. Building the Windows Browser

### Prerequisites
- Node.js 20+
- npm or yarn

```bash
cd windows/desktop

# Install dependencies
npm install

# Run locally in development mode
npm start

# Package for production installer (creates EXE and ZIP)
npm run build:win
```
Build outputs will appear in `windows/desktop/dist/`.

---

## 3. Building the Android Browser

### Prerequisites
- Android Studio Iguana+ or Gradle 8.2+
- Android SDK 34, Build Tools 34.0.0
- JDK 17

```bash
cd android

# Build Release APK
./gradlew assembleRelease
```
The resulting APK will be located in `android/app/build/outputs/apk/release/app-release.apk`.
Copy to `releases/STAUNT-Android.apk` and update `releases/releases.json`.
