Android Installation & Security Guide

1

2
Open the downloaded file from your notification bar or your device's Files / Downloads app.
3

4
Return to the installer and tap Install. Once completed, tap Open to launch STAUNT.
Why does Android show a security warning?
Android displays this standard notice for all applications downloaded directly as an APK rather than from Google Play Store. STAUNT contains zero telemetry and runs strictly in its sandboxed application space. You can verify the authentic package hash before installation using the checksum table below.

Why does SmartScreen show an unrecognized app warning?
STAUNT is an independent open-source release without an expensive commercial Authenticode EV certificate. SmartScreen shows this prompt for newly released builds until cryptographic reputation is established on Microsoft servers. Always verify the SHA-256 hash below.
